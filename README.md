#  Getting Started

Clone the repository

```bash
git clone https://github.com/Sam-uvas/geospatial-residential-development-platform.git
```

Open the project

```bash
cd geospatial-residential-development-platform
```

Run a local server

```bash
python -m http.server
```

Visit

```
http://localhost:8000
```
